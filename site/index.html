The guiding star for your coding agents

Lodestar remembers your rules, won't let an agent say "done" until the tests pass, and pauses before risky commands. It runs locally, inside Claude Code.

How it works

Lodestar plugs into Claude Code's hooks. No cloud account, no stored credentials.

Honest results so far. On a planning task, a plain agent was faster and cheaper. Lodestar's gate caught a real defect the plain agent left behind. We will publish results on failing tasks next.

Quick start

1 · Clone and install

git clone https://github.com/AdarshSingh7647/lodestar-agent
cd lodestar-agent
python -m mgr.cli install --register

2 · Use it in Claude Code

/manager on        start the dashboard
/manager tasks     see verification rounds
/manager remember  store a rule
/manager off       stop
